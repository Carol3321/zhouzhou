# V2 · 手机版

同一棵树，换一套操作方式：**手指直接玩**，摄像头手势降级成可选增强。

V1（根目录的 `christmas-tree-gesture.html` / `main.js`）保持原样，一行没动。V2 是独立页面，相册、模型、wasm 全部复用上级 `assets/`，不重复存图。

线上地址：`https://carol3321.github.io/zhouzhou/v2/` —— 手机浏览器直接点开就能玩，不依赖电脑。

## 手机上怎么玩

| 操作 | 作用 |
|---|---|
| 拖动 | 旋转圣诞树 |
| 空白处双击 | 聚拢 / 散开切换 |
| 点照片 | 看大图；左右滑翻页，下滑回树 |
| 右上角「手势 / 触摸」 | 手动切换输入源 |

手机上默认就是触摸模式：**开场不弹摄像头授权，也不下载手势资源**（模型 7.5MB + wasm 8.7MB）。首屏只拉 8 张缩略图，几百 KB 就出来了。想要手势再点右上角，那一次才会下模型、拉摄像头。

开始拖动时会自动切成触摸并**停掉摄像头**：一是省电省热，二是前置镜头看得见你操作屏幕的那只手，不停掉会和手指抢控制权。点右上角随时切回手势，摄像头会重新拉流。

摄像头没权限、没设备、模型加载失败时，直接退到触摸模式，底栏说明原因，不会卡在"把手举到画面里"。

## 和 V1 的差别

| | V1 | V2 |
|---|---|---|
| 主交互 | 摄像头手势 | 触摸，手势可选 |
| 手机首屏 | 下模型后才可用 | 不下载手势资源，直接可玩 |
| 手机布局 | 未适配 | 竖屏取景、底部操作栏、安全区 |
| 粒子数 | 1500 + 2500 | 手机 900 + 1100 |
| 像素比上限 | 2 | 手机 1.5 |
| 泛光 | 全分辨率 | 手机半分辨率 |
| 检测帧率 | 30fps | 手机 24fps |
| 底部提示 | 手势语义 | 按当前输入源切换文案 |

桌面打开 V2 也能用：鼠标拖动、双击、方向键都在，触摸栏自动隐藏。

## 构建

```bash
npm i                    # 首次
npm run build:v2         # 打包 v2/main.js → v2/bundle.js
python -m http.server 8799
# 打开 http://localhost:8799/v2/
```

只改 `v2/main.js` 不重新打包不会生效，页面加载的是 `v2/bundle.js`。
